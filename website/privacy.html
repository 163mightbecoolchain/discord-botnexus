Политика конфиденциальности

Последнее обновление: 29 августа 2026

Witness — бот для модерации Discord-серверов. Этот документ описывает, какие данные бот обрабатывает, зачем, как долго хранит и как их удалить. Используя Witness, администратор сервера соглашается с описанным порядком обработки данных.

Главное в двух предложениях. Witness не сохраняет тексты сообщений — сообщения анализируются в оперативной памяти и сразу отбрасываются, в базу попадают только числовые характеристики стиля. Данные не продаются, не передаются третьим лицам и используются исключительно для модерации того сервера, где они собраны.

1. Какие данные обрабатываются

Идентификаторы

  • Discord User ID и отображаемое имя — чтобы связать нарушение с участником
  • Guild ID (ID сервера) — настройки хранятся отдельно для каждого сервера
  • Channel ID и Role ID — для настроек логирования и карантина

Записи модерации

  • Предупреждения, муты, кики, баны: кто, кому, когда, причина, срок
  • Апелляции: текст обращения участника и решение модератора
  • Заявки на бан, созданные при накоплении предупреждений

Характеристики стиля письма (стилометрия)

Для выявления обхода блокировки через дополнительные аккаунты бот строит статистический профиль манеры письма. В профиль входят:

  • частоты служебных слов и характерных опечаток
  • доли сообщений с пунктуацией, заглавными буквами, эмодзи
  • средняя длина слова и сообщения, лексическое разнообразие
  • интервалы между сообщениями и распределение активности по часам
  • сжатые n-граммы (последовательности символов и слов)

Тексты сообщений в базу данных не записываются. Сообщение обрабатывается в оперативной памяти, из него извлекаются перечисленные числовые признаки, после чего текст отбрасывается. Восстановить исходное сообщение из профиля невозможно.

Служебные данные

  • Учёт приглашений: код инвайта, кто создал, сколько переходов
  • Даты рождения — только если участник указал их добровольно командой
  • Токены авторизации веб-панели — в подписанной cookie у пользователя, не в базе

2. Зачем это нужно

ДанныеНазначение
Профили стиляОбнаружение дополнительных аккаунтов заблокированных участников
Журнал модерацииИстория решений, прозрачность работы команды модераторов
АпелляцииВозможность оспорить наказание
Учёт приглашенийОтслеживание источников трафика и рейдов
Настройки сервераРабота функций бота согласно правилам сервера

Данные не используются для рекламы, обучения моделей машинного обучения и не объединяются между разными серверами.

Удаление бота с сервера прекращает сбор данных. Для полного удаления накопленных записей администратор может обратиться в поддержку.

4. Где и как хранятся данные

База данных SQLite размещается на приватном томе хостинга Railway и доступна только процессу бота. Внешнего доступа к базе нет. Соединение с веб-панелью защищено HTTPS, авторизация выполняется через официальный OAuth2 Discord — пароль от Discord боту не передаётся и ему неизвестен.

5. Передача третьим лицам

Данные не продаются и не передаются. Ограниченные исключения:

  • Discord — как платформа, через которую бот работает
  • Railway — хостинг-провайдер, где размещены бот и база
  • Groq и Google Gemini — при использовании функций с искусственным интеллектом им передаются агрегированные показатели сходства профилей. Тексты сообщений участников этим сервисам не отправляются.

6. Права участников

  • Узнать, какие данные собраны — командой профиля или через администратора сервера
  • Оспорить наказание — через систему апелляций в личных сообщениях бота
  • Потребовать удаления данных — обратившись к администратору сервера или в поддержку
  • Отказаться от сбора — покинув сервер, где работает бот

7. Несовершеннолетние

Discord запрещает использование сервиса лицами младше 13 лет (в отдельных странах — младше установленного местным законом возраста). Witness намеренно не собирает данные таких пользователей. При поступлении сведений о том, что данные принадлежат лицу, не достигшему допустимого возраста, они будут удалены.

8. Изменения политики

При существенных изменениях дата в начале страницы обновляется, а уведомление публикуется на сервере поддержки. Продолжение использования бота после изменений означает согласие с новой редакцией.

9. Контакты

По вопросам обработки данных и запросам на удаление — сервер поддержки Witness.
