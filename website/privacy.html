Политика конфиденциальности

Последнее обновление: 7 октября 2026

Witness — бот для модерации Discord-серверов. Этот документ описывает, какие данные бот обрабатывает, зачем, как долго хранит и как их удалить. Используя Witness, администратор сервера соглашается с описанным порядком обработки данных.

Главное. Witness не строит профили пользователей и не хранит переписку. Текст сообщений бот читает только для модерации: проверки на фишинг и скам, логов удалённых и изменённых сообщений и команд, которые участник вызывает сам. Данные не продаются и не используются для рекламы или обучения моделей.

1. Какие данные обрабатываются

Идентификаторы

  • Discord User ID и отображаемое имя — чтобы связать действие с участником
  • Guild ID (ID сервера) — настройки и записи хранятся отдельно для каждого сервера
  • Channel ID и Role ID — для настроек логирования, карантина, ролей за реакции

Содержимое сообщений

  • Проверка на фишинг и скам. Новые сообщения проверяются в оперативной памяти. При срабатывании модераторам в лог-канал сервера отправляется алерт с фрагментом сообщения. В базе сохраняется только запись об алерте: тип угрозы, сработавшее правило и, для поддельных ссылок, сама подозрительная ссылка — до 90 дней.
  • Проверка на дублирование (спам). В базе хранится только хеш текста без самого текста — 7 дней.
  • Картинки. Бот проверяет, нет ли в метаданных изображения GPS-координат, и предупреждает модераторов. Изображение не сохраняется.
  • Логи сервера. Если администратор включил логирование, текст удалённых и изменённых сообщений отправляется в лог-канал этого же сервера. В базу бота он не записывается.

Записи модерации

  • Предупреждения, муты, кики, баны: кто, кому, когда, причина, срок
  • Апелляции: текст обращения участника и решение модератора
  • Заявки на бан и алерты безопасности

Данные, которые участник вводит сам

  • Тексты напоминаний, предложений, заметок к инвайтам
  • Дата рождения — только если участник указал её командой
  • Ники в играх — для игровых команд и привязки аккаунта Albion

Служебные данные

  • Учёт приглашений: код инвайта, кто создал, кто по нему зашёл
  • Опыт и монеты: счётчики, без текста сообщений
  • Количество сообщений по часам (для статистики сервера) — только в памяти, без привязки к участникам
  • Токены авторизации веб-панели — в подписанной cookie у пользователя, не в базе

Общая база угроз

Администратор может вручную отметить участника как угрозу (команда /q report). В общую для всех серверов базу попадают: User ID, уровень угрозы, причина, число жалоб и ID серверов, которые пожаловались. Другие серверы с ботом видят эту отметку при проверке участника.

4. Где и как хранятся данные

База данных SQLite размещается на приватном томе хостинга Railway и доступна только процессу бота. Внешнего доступа к базе нет. Соединение с веб-панелью защищено HTTPS, авторизация выполняется через официальный OAuth2 Discord — пароль от Discord боту не передаётся и ему неизвестен.

5. Передача третьим лицам

Данные не продаются. Сторонним сервисам передаётся только необходимое:

  • Discord — платформа, через которую работает бот
  • Railway — хостинг, где размещены бот и база
  • Groq, Google Gemini, Anthropic — ИИ-сервисы. Им отправляется только то, что нужно для команды, которую вызвал пользователь: вопрос в /ai и /askalbion, текст в /translate, последние сообщения канала (до 50, с отображаемыми именами) в /summarize, имя и роли участника в /roast. Автоматически, без команды, сообщения ИИ-сервисам не отправляются.
  • Pollinations — описание картинки из /imagine
  • Игровые API (Albion Online, Riot, Steam, Lost Ark, сервисы погоды) — ник или запрос, введённый в игровой команде

6. Права участников

  • Узнать, какие данные собраны — через администратора сервера или поддержку
  • Оспорить наказание — через систему апелляций в личных сообщениях бота
  • Потребовать удаления данных — обратившись к администратору сервера или в поддержку
  • Отказаться от сбора — покинув сервер, где работает бот

7. Несовершеннолетние

Discord запрещает использование сервиса лицами младше 13 лет (в отдельных странах — младше установленного местным законом возраста). Witness намеренно не собирает данные таких пользователей. При поступлении сведений о том, что данные принадлежат лицу, не достигшему допустимого возраста, они будут удалены.

8. Изменения политики

При существенных изменениях дата в начале страницы обновляется, а уведомление публикуется на сервере поддержки. Продолжение использования бота после изменений означает согласие с новой редакцией.

9. Контакты и удаление данных

По вопросам обработки данных и запросам на удаление — сервер поддержки Witness. Запросы обрабатываются вручную.

Privacy Policy

Last updated: October 7, 2026

Witness is a moderation bot for Discord servers. This document explains what data the bot processes, why, how long it is kept and how to have it deleted. By using Witness, a server administrator agrees to the data processing described here.

In short. Witness does not build user profiles and does not store conversations. The bot reads message content only for moderation: phishing and scam detection, logs of deleted and edited messages, and commands that a member runs themselves. Data is never sold and is not used for advertising or for training any models.

1. What data is processed

Identifiers

  • Discord User ID and display name — to link an action to a member
  • Guild ID (server ID) — settings and records are kept separately for each server
  • Channel and Role IDs — for logging, quarantine and reaction role settings

Message content

  • Phishing and scam detection. New messages are checked in memory. On a match, moderators receive an alert with an excerpt of the message in the server's log channel. The database keeps only the alert record: threat type, matched rule and, for spoofed links, the flagged link itself — for up to 90 days.
  • Duplicate (spam) detection. Only a one-way hash of the text is stored, never the text itself — for 7 days.
  • Images. The bot checks image metadata for GPS coordinates and warns moderators. Images are not stored.
  • Server logs. If an administrator enables logging, the text of deleted and edited messages is posted to that server's log channel. It is not written to the bot's database.

Moderation records

  • Warnings, timeouts, kicks, bans: who, whom, when, reason, duration
  • Appeals: the member's appeal text and the moderator's decision
  • Ban requests and security alerts

Data members enter themselves

  • Texts of reminders, suggestions and invite notes
  • Date of birth — only if the member set it with a command
  • In-game names — for game commands and Albion account linking

Service data

  • Invite tracking: invite code, who created it, who joined with it
  • Levels and coins: counters only, no message text
  • Messages per hour (for server statistics) — in memory only, not linked to members
  • Dashboard login tokens — in a signed cookie in the user's browser, not in the database

Shared threat list

An administrator can manually flag a member as a threat (/q report). The list shared across all servers stores: User ID, threat level, reason, number of reports and the IDs of the servers that reported. Other servers using the bot see this flag when checking the member.

Removing the bot from a server stops data collection. To delete all stored records, the administrator can contact support.

4. Where and how data is stored

The SQLite database is hosted on a private volume at our hosting provider (Railway) and is accessible only by the bot process; there is no external access to it. Data is encrypted at rest at the storage level by the hosting provider. The dashboard uses HTTPS, and login goes through Discord's official OAuth2 — the bot never receives or knows your Discord password.

5. Third parties

Data is never sold. Only what is necessary is shared with:

  • Discord — the platform the bot runs on
  • Railway — hosting for the bot and its database
  • Groq, Google Gemini, Anthropic — AI providers. They receive only what a command the user ran needs: the question in /ai and /askalbion, the text in /translate, the last messages of the channel (up to 50, with display names) in /summarize, a member's name and roles in /roast. Messages are never sent to AI providers automatically, without a command.
  • Pollinations — the image description in /imagine
  • Game APIs (Albion Online, Riot, Steam, Lost Ark, weather services) — the name or query entered in a game command

6. Your rights

  • Find out what data is stored — via the server administrator or support
  • Dispute a punishment — through the appeal system in the bot's DMs
  • Request deletion — by contacting the server administrator or support
  • Opt out of processing — by leaving the server where the bot is used

7. Children

Discord does not allow users under 13 (or the minimum age set by local law in some countries). Witness does not knowingly collect data from such users. If we learn that data belongs to a person below the permitted age, it will be deleted.

8. Changes to this policy

When the policy changes materially, the date at the top is updated and a notice is posted on the support server. Continued use of the bot after changes means acceptance of the new version.

9. Contact and data deletion

For questions about data processing and deletion requests, contact us on the Witness support server. Requests are handled manually.
